# 구현 검증 기록

갱신일: 2026-10-15 · 기능 찾기 개편 버전 2.0.0

이번 검증은 사용자가 하고 싶은 일을 문장으로 입력하고, 맞는 기능을 확인한 뒤 해당 화면으로 이동하는 흐름을 대상으로 수행했습니다. 이전 버전의 결과를 소급하여 사용하지 않았습니다.

## 자동 검사

| 검사                           | 결과                                                       |
| ------------------------------ | ---------------------------------------------------------- |
| `node --test tests/*.test.mjs` | 19개 통과                                                  |
| `node scripts/check.mjs`       | 공개 파일 22개의 범위, 에셋 참조, 자격 증명 패턴 검사 통과 |
| `node --check app.js`          | JavaScript 구문 검사 통과                                  |

기능 검색 테스트는 표시 예시, 한국어 표현 변형, 모호한 통화·사진 요청, 부정·복수 요청, 미지원 기능, 유니코드 정규화와 결과 목록 제한을 확인합니다.

상태 테스트는 텍스트·샘플 전송, 독립 초안, 설정 저장·복원, 이전 저장 형식의 초안 보존, 입력 길이, 허용된 프로필 그림, 잘못된 데이터 차단, 최근 300개 기록 제한을 확인합니다.

## 브라우저 확인

Codex 내장 Chromium 브라우저에서 실제 버튼·입력·키보드 조작으로 확인했습니다.

| 과업                | 확인 결과                                                                    |
| ------------------- | ---------------------------------------------------------------------------- |
| 홈·친구·대화·도움말 | 각 화면 이동, 도움말에서 기능 찾기 예시로 연결                               |
| 사진 보내기         | 문장 입력 → 결과 → 친구 선택 → 샘플 사진 선택 → 대화 표시                    |
| 영상·음성 통화      | 각 기능 검색 → 친구 선택 → 통화 화면 시연 → 종료                             |
| 모호한 요청         | “통화하고 싶어”에 영상·음성 후보를 함께 표시                                 |
| 선물·이모티콘       | 각 기능 검색 → 친구·항목 선택 → 가상 대화 표시                               |
| 글자 크기           | 검색으로 설정에 도착, 더 큰 글자 미리 보기·적용                              |
| 프로필·알림         | 그림·이름·소개 저장, 알림 설정값 변경, 완료 화면 확인                        |
| 음성 입력 예시      | 기존 초안을 보존하고 예시 문장 추가, 직접 전송 전 확인                       |
| 입력 공간 부족      | 500자 초안은 보존하며 음성 예시를 추가하지 못한 이유 표시                    |
| 범위 밖·부정 표현   | 친구 찾기 요청의 결과 없음 안내, 부정 표현의 확인 안내                       |
| 기능 목록           | 9개 기능 목록 표시와 해당 화면 이동·뒤로 복귀                                |
| 저장 복원           | 새로고침 후 대화·초안 복원, 큰 글자·선택한 프로필 그림 유지                  |
| 입력 한도           | 검색 200자, 메시지 500개 코드 포인트, 이름 20자·소개 80자 제한               |
| 키보드              | 검색 입력에서 Tab으로 찾기 버튼 이동, Enter 실행, Esc 확인창 취소            |
| 모드 변경           | 취소·확정·간편 모드 복귀, 이전 확정 뒤 Esc 취소가 실행을 일으키지 않음       |
| 초기화              | 명시적 확인 뒤 체험 대화·설정 초기화와 홈 복귀                               |
| 반응형              | 320px·390px에서 가로 넘침 없음, 큰 글자와 긴 입력 확인. 데스크톱 1440px 확인 |
| 문자열·콘솔         | HTML처럼 보이는 채팅을 문자 그대로 표시. 확인한 흐름에서 콘솔 오류 없음      |

실제 카메라·마이크·전송·결제 API를 호출하지 않는 것은 코드 검토와 각 기능의 시연 화면을 통해 확인했습니다. 기기 권한이나 실제 카카오톡 연동을 테스트한 것으로 해석하지 않습니다.

## 검증의 범위

이 기록은 구현이 정한 동작을 수행하는지 확인하기 위한 문서입니다. 실제 사용자가 자신의 표현으로 원하는 기능을 쉽게 찾는지에 대해서는 별도의 사용자 관찰이 필요합니다.

Figma 원본은 2026-10-14 초안으로, 이번 기능 찾기 개편이 아직 반영되지 않았습니다. Starter 요금제 MCP 호출 한도로 수정 대기 중이며, 기존 Figma 확인을 이번 웹 개편의 검증 결과로 사용하지 않습니다.

실제 사용자 사용성 테스트, 개선 효과 측정, 저장 공간 부족을 강제로 발생시키는 브라우저 검사, 모든 브라우저·기기·보조기술 조합에 대한 전수 검사는 실시하지 않았습니다. 기능 찾기는 정해진 기능 목록과 로컬 규칙으로 동작하며 외부 AI나 실제 카카오톡 서비스를 호출하지 않습니다.
