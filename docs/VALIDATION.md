# 구현 검증 기록

검증일: 2026-10-14

## 자동 검사

- `node --test tests/*.test.mjs`: 상태 테스트 13개 통과
- `node scripts/check.mjs`: 로컬 에셋 존재, 공개 파일 범위, 자격 증명 패턴 검사 통과
- `node --check app.js`: JavaScript 구문 검사 통과

테스트는 빈 입력, 전송 중 중복 방지, 같은 메시지 재시도, 모드 변경과 저장 복원, 중단된 전송 복구, 한글 검색, Unicode 길이 제한, 손상된 저장 데이터의 정규화를 다룹니다. 문자열의 안전한 화면 표시는 별도 브라우저 확인을 병행했습니다.

## 브라우저 확인

Chrome 및 Codex 인앱 브라우저에서 다음을 직접 조작했습니다.

| 확인 항목 | 결과 |
|---|---|
| 친구 선택, 자유 메시지 입력·전송 | 진행 상태 뒤 완료 표시 |
| 작성 중 목록 이동과 같은 대화 복귀 | 초안 유지 및 작성 중 표시 |
| 새로고침 후 대화·초안 복원 | 입력 내용과 전송 완료 상태 유지 |
| 이름 검색 및 결과 없음 복구 | 부분 이름 검색과 전체 친구 복귀 동작 |
| 전송 실패 예시와 재시도 | 같은 메시지 ID와 말풍선 수를 유지하며 완료 |
| 도움말 목록·답변·과업 연결 | 안내를 읽은 뒤 친구 선택으로 이동 |
| 빈 대화 목록 | 친구 선택 행동 표시 |
| 모드 변경 취소·확정·재방문·복귀 | 모드와 초안 유지 |
| 501개 이모지 입력 | Unicode 코드 포인트 기준 500개로 제한 |
| HTML처럼 생긴 입력 | 태그 실행이나 이미지 생성 없이 글자로 표시 |
| 모바일 320px·390px | 문서 가로 넘침 없음, 메시지 입력·전송 동작 |
| 브라우저 콘솔 | 검토한 흐름에서 오류·경고 없음 |

키보드로 재시도한 뒤 입력창으로 초점이 이동하는 것을 확인했습니다. 모든 브라우저·기기와 보조기술 조합을 전수 검사한 것은 아닙니다. 전송 중 새로고침 복구와 손상된 저장 데이터는 자동 상태 테스트로 확인했으며, 저장 차단·저장 공간 부족 상황은 브라우저에서 강제로 재현하지 않았습니다.
