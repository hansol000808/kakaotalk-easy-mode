# 카카오톡 간편 모드

핵심 메뉴만 기본 화면에 남기고, 그 밖의 기능은 “생일 선물 보내고 싶어”처럼 일상 문장으로 찾아 이용하는 카카오톡 간편 모드 컨셉 데모입니다. 홈에는 친구·대화·기능 찾기·도움말을 크게 배치하고, 다른 기능은 검색 결과를 확인해 해당 체험 화면으로 이동하도록 구성했습니다.

모호한 요청에는 관련 기능 후보를 제시합니다. 검색 결과가 없으면 다시 입력하거나 지원 기능 목록을 확인해 탐색을 이어갈 수 있습니다. 웹 데모는 HTML, CSS, JavaScript로 동작하며 별도의 서버 데이터베이스나 로그인은 사용하지 않습니다.

**[웹 데모 열기](https://hansol000808.github.io/kakaotalk-easy-mode/)**

카카오의 공식 서비스가 아닌 컨셉 데모입니다. 모든 인물과 대화는 가상 데이터이며, 실제 카카오톡 계정이나 메시지 서비스에 연결하지 않습니다.

## 주요 기능

| 기능 | 동작 |
|---|---|
| 하고 싶은 말로 기능 찾기 | 최대 200자의 문장을 정해진 기능 목록과 한국어 표현 규칙에 대응시킵니다. 기능 이름과 설명을 확인하고 해당 체험 화면을 엽니다. |
| 모호하거나 일치하지 않는 요청 | “통화하고 싶어”에는 음성·영상 후보를 함께 보여 줍니다. 결과가 없으면 다시 적기와 지원 기능 목록을 안내합니다. |
| 사진·선물·이모티콘 | 가상 친구와 샘플 항목을 선택해 대화에 표시합니다. 실제 전송·주문·결제는 없습니다. |
| 음성·영상통화 | 가상 친구를 선택하고 통화 화면과 종료 흐름을 체험합니다. 마이크·카메라는 사용하지 않습니다. |
| 글자 크기·프로필·알림 | 기본·더 큰 글자, 시연용 프로필 그림 3종·이름·소개 문구, 데모 알림 설정값을 로컬에 저장합니다. |
| 음성 입력 예시 | 준비된 예시 문구를 기존 초안 뒤에 추가합니다. 실제 음성 인식은 하지 않으며 입력 후 직접 확인하고 전송합니다. |
| 친구·대화·메시지 | 가상 친구를 선택해 최대 500자의 메시지를 즉시 대화에 표시합니다. 이전 대화와 작성 중인 초안을 이어 볼 수 있습니다. |
| 도움말·모드 변경 | 기능 찾기를 과업별로 안내합니다. 확인창을 거쳐 기본 모드의 비교용 화면으로 전환하고 간편 모드로 돌아옵니다. |

입력 길이는 Unicode 코드 포인트 기준입니다. 기능 찾기는 LLM이나 외부 AI를 호출하지 않으며 모든 자유 문장을 이해하는 시스템은 아닙니다.

## 사용 방법

1. 홈의 **기능 찾기**를 엽니다.
2. “사진 보내고 싶어”처럼 하고 싶은 일을 적거나 예시 문장을 선택합니다.
3. 결과의 기능 이름과 설명을 확인하고 **이 기능 열기**를 선택합니다.
4. 해당 화면에서 친구·샘플을 고르거나 설정을 바꿉니다.
5. **뒤로** 또는 **다른 기능 찾기**를 통해 탐색을 이어갑니다.

| 입력 예시 | 연결되는 기능 |
|---|---|
| 사진 보내고 싶어 | 사진 보내기 |
| 얼굴 보고 통화하고 싶어 | 영상통화 |
| 전화하고 싶어 | 음성통화 |
| 생일 선물 보내고 싶어 | 선물하기 |
| 글씨가 너무 작아 | 글자 크기 |
| 내 사진 바꾸고 싶어 | 프로필 그림·이름·소개 |
| 알림 소리가 시끄러워 | 알림 설정 |
| 이모티콘 보내고 싶어 | 이모티콘 |
| 말로 메시지를 쓰고 싶어 | 음성 입력 예시 |

화면 밖의 예시 버튼은 해당 문장으로 기능을 찾습니다. **체험 초기화**를 선택하고 확인하면 이 브라우저의 체험 대화·초안·설정이 초기화됩니다.

## 저장 및 복구

- 상태는 현재 브라우저의 `localStorage`에 저장합니다. 다른 기기나 브라우저와 동기화되지 않으며 사이트 데이터를 삭제하면 저장 상태도 사라집니다.
- 전체 대화에서 최근 메시지 300개까지 유지합니다. 한도를 넘으면 오래된 메시지부터 제외합니다.
- 상대별 초안을 보관합니다. 샘플 사진·선물·이모티콘을 보내도 작성 중인 글은 보존합니다.
- 프로필 이름은 20자, 소개 문구는 80자까지 입력합니다. 프로필 그림은 웃는 얼굴·꽃·산의 시연용 그림 중 고릅니다.
- 이전 버전의 저장 데이터도 읽으며, 아직 전송되지 않았던 텍스트는 초안으로 보존합니다.
- 저장이 차단되거나 공간이 부족하면 안내를 표시하고 현재 탭에서 동작을 이어갑니다. 최근 변경은 저장되지 않을 수 있습니다.
- 입력한 내용을 메시지 서버에 전송하지 않습니다. 가상 문구로 기능을 체험할 수 있습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다. 별도의 패키지 설치나 빌드 과정은 없습니다.

```sh
git clone https://github.com/hansol000808/kakaotalk-easy-mode.git
cd kakaotalk-easy-mode
node scripts/serve.mjs
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)에 접속합니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

웹 화면은 정적 파일로 구성되어 GitHub Pages에서 제공할 수 있습니다. `scripts/serve.mjs`는 로컬 확인용 서버입니다.

## 검사 실행

```sh
node --test tests/*.test.mjs
node scripts/check.mjs
node --check app.js
```

- 19개 테스트는 기능별 표현, 모호한·미지원 요청, 메시지·샘플 데이터, 초안, 설정, 이전 저장 데이터, 입력 제한과 잘못된 데이터를 다룹니다.
- 공개 파일 검사는 로컬 에셋 존재, 제외 대상 파일 및 자격 증명 패턴을 확인합니다.
- 확인한 환경과 결과는 [검증 기록](docs/VALIDATION.md)에 정리되어 있습니다.

## 기술 구성과 파일 구조

| 경로 | 역할 |
|---|---|
| `index.html` | 페이지 구조, 체험 영역, 기능 찾기 예시와 확인창 |
| `styles.css` | 화면 스타일과 반응형 배치 |
| `app.js` | 화면 렌더링, 기능별 목적지, 입력 이벤트와 브라우저 저장 |
| `features.js` | 9개 기능 목록, 예시 문장과 한국어 표현 규칙 |
| `state.js` | 가상 데이터, 입력 제한, 전송, 초안, 설정과 저장 데이터 정규화 |
| `assets/icons/` | Lucide 기반 SVG 아이콘 |
| `tests/*.test.mjs` | Node.js 기본 테스트 러너를 사용하는 기능 탐색·상태 테스트 |
| `scripts/serve.mjs` | 로컬 정적 파일 서버 |
| `scripts/check.mjs` | 에셋과 공개 파일 범위 검사 |
| `docs/DESIGN.md` | 기획 배경, 화면 목적, 기능 대응과 구현 범위 |
| `docs/VALIDATION.md` | 검사 결과와 확인 범위 |

브라우저에서는 ES 모듈과 `localStorage`를 사용합니다. 검색과 전송은 외부 API 없이 로컬에서 처리합니다. 아이콘과 시연용 그림 출처는 [에셋 문서](assets/README.md), 라이선스는 [LUCIDE-LICENSE](assets/LUCIDE-LICENSE)를 참고하세요.

## Figma 프로토타입과 웹 데모

Figma에서는 핵심 화면과 사용자 흐름을 프로토타이핑했습니다. 기능 찾기, 결과 확인, 기능별 화면 이동과 함께 모호한 요청 및 검색 결과 없음 상태를 연결합니다.

웹 데모에서는 사용자가 직접 입력한 문장을 규칙으로 처리하고, 기능 후보 선택부터 체험 화면까지 이어지는 동작을 구현했습니다. Figma는 준비된 화면과 상태 전환을 보여 주며, 자유 입력의 검색 처리와 대화·초안·설정 저장은 웹에서 동작합니다. 자세한 설계 기준은 [설계 문서](docs/DESIGN.md)를 참고하세요.

## 구현 범위와 제약

- 사진·선물·이모티콘은 준비된 샘플이고 통화·음성 입력은 시연입니다. 실제 통신, 결제, 카카오톡 연동, 로그인·계정 동기화는 구현하지 않았습니다.
- 알림 설정은 데모의 설정값만 바꾸며 기기나 카카오톡의 실제 알림에는 영향을 주지 않습니다.
- 기본 모드는 메뉴가 많은 화면을 비교하기 위한 예시이며 각 메뉴의 실제 기능은 제공하지 않습니다.
- 자동 테스트와 화면 점검은 실제 사용자 사용성 평가를 대신하지 않습니다. 모든 브라우저·기기·보조기술 조합을 검사한 것은 아닙니다.
- 실제 고령층 사용자를 대상으로 한 사용성 테스트와 개선 효과 측정은 수행하지 않았습니다.
