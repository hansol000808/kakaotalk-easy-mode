# 카카오톡 간편 모드

카카오톡 간편 모드 | 디지털 포용성을 위한 UX/UI 리디자인과 인터랙티브 웹 데모

복잡한 메신저 화면에서 필요한 기능을 찾기 어려운 사용자를 위해 핵심 과업과 복구 동작을 설계한 개인 포트폴리오 프로젝트입니다. 큰 메뉴와 명확한 이름으로 친구 찾기, 대화 시작, 메시지 입력과 전송 상태를 체험할 수 있습니다.

- 저장소: [hansol000808/kakaotalk-easy-mode](https://github.com/hansol000808/kakaotalk-easy-mode)
- 화면 목적과 동작 기준: [설계 문서](docs/DESIGN.md)
- 실행한 검사와 확인 범위: [검증 기록](docs/VALIDATION.md)
- 웹 아이콘 출처와 Figma와의 차이: [에셋 문서](assets/README.md)

카카오의 공식 서비스가 아닌 컨셉 리디자인입니다. 모든 인물과 대화는 가상 데이터이며, 실제 카카오톡 계정이나 메시지 서비스에 연결하지 않습니다.

## 프로젝트의 출발점

| 시기 | 수행 범위 |
|---|---|
| 2020년 | 중앙대학교 「디자인적 사고와 문제해결」 수업의 팀 아이디어 제안 프로젝트. 여러 사용자 맥락을 검토하고 디지털 취약계층을 위한 간편 모드를 제안했습니다. 실제 앱이나 작동하는 프로토타입은 구현하지 않았습니다. |
| 2026년 | 당시 간편 모드 아이디어를 선정해 처음으로 Figma 화면·프로토타입을 제작하고, 이를 브라우저에서 동작하는 웹 데모로 발전시켰습니다. 화면, 공통 요소와 주요 예외 상태를 구체화하는 과정에 생성형 AI의 제작 지원을 활용했습니다. |

한재혁이 2020년 팀 프로젝트 참여 경험을 바탕으로 진행한 후속 리디자인입니다.

## 체험할 수 있는 흐름

- 홈에서 친구 목록이나 대화 목록으로 이동하고 대화 상대를 선택합니다.
- 최대 500자의 메시지를 입력합니다. 전송은 약 900ms 동안 진행 상태를 보여 주는 시뮬레이션입니다.
- 전송 실패 상태에서는 같은 메시지를 다시 보냅니다. 재시도가 별개의 메시지를 중복 생성하지 않도록 설계했습니다.
- 작성 중인 초안과 가상 대화 상태를 브라우저에 저장해 다음 방문에서 이어 봅니다.
- 친구 검색과 결과 없음, 질문형 도움말, 빈 대화 목록의 다음 행동을 확인합니다.
- 모드 변경을 취소하거나 확정합니다. 일반 모드는 변경 완료 안내까지만 시연하고 간편 모드로 돌아올 수 있습니다.

사진·영상 전송, 전화·음성인식, 실제 상대와의 통신, 로그인과 계정 동기화는 구현 범위에 포함하지 않습니다.

## 브라우저 저장 방식

시연 상태는 현재 브라우저의 `localStorage`에 저장하며 메시지는 최근 300개까지 유지합니다. 다른 기기나 브라우저와 동기화되지 않으며 사이트 데이터를 지우면 저장 상태도 사라집니다. 전송 도중 새로고침하면 진행 중이던 메시지를 실패 상태로 복원하고 같은 메시지를 다시 보낼 수 있습니다.

브라우저가 저장을 차단하거나 저장 공간이 부족하면 현재 탭의 메모리에서 시연을 이어갑니다. 이때 최근 변경 사항이 저장되지 않을 수 있다는 안내를 표시합니다. 새로고침하면 마지막으로 저장된 상태가 남아 있을 수 있으며, 방금 입력하거나 보낸 내용은 복원되지 않을 수 있습니다. 가상 문구로 체험할 수 있고 서버에 메시지를 보내지 않습니다.

Figma는 준비된 프레임 사이를 이동하는 시연이고, 웹 데모는 브라우저에서 직접 입력하고 상태를 저장하는 구현입니다. Figma 원본은 현재 팀 접근 권한으로 관리하므로 외부 평가자의 접근을 보장하지 않습니다. 이 저장소의 웹 데모와 설계 문서를 기준으로 프로젝트를 살펴볼 수 있습니다.

## 로컬 실행

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```sh
git clone https://github.com/hansol000808/kakaotalk-easy-mode.git
cd kakaotalk-easy-mode
node scripts/serve.mjs
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

테스트 실행:

```sh
node --test tests/*.test.mjs
```

위 명령은 테스트 실행 방법입니다. 자동 테스트는 실제 사용자와 진행하는 사용성 테스트를 대신하지 않습니다.

## 공개 범위와 검증의 한계

이 저장소에는 웹 데모 코드, 가상 시연 데이터, 공개용으로 선별한 이미지와 설계 문서만 포함합니다. 원본 수업 PPT·PDF·영상, 팀원 개인정보가 담긴 자료와 내부 작업 기록은 공개 대상에서 제외했습니다.

실제 사용자 사용성 테스트와 개선 효과 측정은 아직 수행하지 않았습니다. 원본에 남아 있는 팀의 조사 활동 기록을 이번 데모의 효과 검증으로 해석하지 않습니다. 화면과 동작 검토, 자동 테스트를 근거로 오조작 감소율이나 과업 시간 단축을 주장하지 않습니다.

## 생성형 AI 활용

후속 리디자인에는 Codex를 통한 원본 자료 정리, Figma 화면·컴포넌트 제작, 웹 코드 작성과 점검 지원을 활용했습니다. 한재혁은 기존 경험과 프로젝트 방향, 후속 작업의 범위를 제시했습니다.
