# 웹 아이콘

네 가지 UI 아이콘은 [Lucide 공식 저장소](https://github.com/lucide-icons/lucide)의 SVG를 사용합니다. 원본 라이선스는 [LUCIDE-LICENSE](LUCIDE-LICENSE)에 보존했습니다.

| 파일 | 원본 아이콘 |
|---|---|
| icons/friends.svg | users-round |
| icons/chats.svg | messages-square |
| icons/search.svg | search |
| icons/help.svg | circle-question-mark |

2026-10-14에 원본 SVG를 내려받았으며 SVG 도형을 수정하지 않았습니다. 웹 표시 크기는 CSS에서 지정합니다. Figma의 자체 제작 아이콘은 도구의 호출 한도와 브라우저 내보내기 제한으로 추출하지 못해 웹에서는 Lucide 아이콘으로 대체했습니다. 웹의 색상·레이아웃·주요 화면 구조는 Figma 설계 명세를 따르되, 반응형 소개 페이지와 자유 입력은 웹 구현 범위입니다.
