# 웹 아이콘

네 가지 UI 아이콘은 [Lucide 공식 저장소](https://github.com/lucide-icons/lucide)의 SVG를 사용합니다. 원본 라이선스는 [LUCIDE-LICENSE](LUCIDE-LICENSE)에 보존했습니다.

| 파일              | 원본 아이콘          |
| ----------------- | -------------------- |
| icons/friends.svg | users-round          |
| icons/chats.svg   | messages-square      |
| icons/search.svg  | search               |
| icons/help.svg    | circle-question-mark |

2026-10-14에 원본 SVG를 내려받았으며 SVG 도형을 수정하지 않았습니다. 웹 표시 크기는 CSS에서 지정합니다. Figma의 자체 제작 아이콘과 별개로 웹에서는 Lucide 아이콘을 사용합니다.

사진 선택 화면의 산책길·꽃·바다 그림은 CSS로 그린 시연용 이미지입니다. 선물·이모티콘·프로필 그림은 기기의 기본 이모지 글꼴로 표시합니다. 개인 사진이나 실제 상품 이미지를 사용하지 않습니다.

2026-10-15의 기능 찾기 화면과 기능별 체험 화면은 웹에서 새로 구성했습니다. Figma 원본에는 이번 개편이 아직 반영되지 않았으며, 현재 웹과 Figma의 화면이 동일하지 않습니다.
