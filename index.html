어디에 있는지 모르겠다면?

사진을 보내고 싶어도 메뉴 이름과 위치를 모르면 시작하기 어렵습니다. 화면에 모든 기능을 늘어놓으면 원하는 일을 고르는 부담도 커집니다.

2020년 팀이 제안한 간편 모드는 홈을 단순하게 유지하면서, 사용자가 하고 싶은 일을 말로 설명해 기능을 찾도록 구상했습니다. 2026년에는 Figma로 화면과 사용자 흐름을 프로토타이핑하고, 기능 검색부터 체험 화면까지 이어지는 웹 데모를 구현했습니다.

02

기능명 대신 하고 싶은 말

“얼굴 보고 통화하고 싶어”를 입력하면 영상통화를 안내합니다. 사용자가 쓰는 표현과 서비스의 기능 이름을 연결합니다.

일상 언어기능 이름을 몰라도
03

맞는 기능을 확인하고 바로 이동

결과에서 기능 이름과 할 수 있는 일을 확인합니다. 원하는 항목을 선택하면 사진 보내기, 통화, 선물하기 같은 해당 기능의 체험 화면으로 이동합니다.

03 / NEXT QUESTION

화면을 만든 다음에는,
사용자에게 배워야 합니다.

사용자가 쓰는 말은 다양합니다. 다음 단계는 디지털 환경이 낯선 사용자가 자신의 표현으로 원하는 기능을 찾고, 결과를 이해한 뒤 해당 화면으로 이동할 수 있는지 관찰하는 것입니다.

현재 기능 찾기는 정해진 기능 목록과 로컬 규칙으로 동작합니다. AI 호출 없이 탐색 흐름을 시연하며, 실제 사용자 테스트와 사용성 개선 효과 측정은 아직 진행하지 않았습니다.
